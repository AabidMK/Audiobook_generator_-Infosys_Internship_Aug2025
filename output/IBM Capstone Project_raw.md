PROBLEM STATEMENT
Manual  college  admission  processes  involve  time-consuming  inquiries  
about  eligibility,  courses,  fees, cutoffs,  and deadlines . Students  often  
struggle  to get accurate,  updated  information  from  official  sources  or 
helplines  . There  is a growing  need  for an AI-powered  assistant  that can 
provide  transparent,  real-time,  and personalized  responses  to student  
queries  related  to admissions  using  trusted  institutional  data.
PROPOSED SOLUTION
❖The proposed system is a College Admission Agent built using IBM Watsonx.ai and 
powered by RAG (Retrieval -Augmented Generation). It helps students get accurate 
admission details through natural language queries.
❖Key components:
-Retrieval: Uses Tavily andWikipedia Search to fetch real -time data
-Generation : Uses Granite -13B Chat Model to generate human -like responses
-Built on IBM Cloud Lite using Watsonx.ai Studio
-Deployed in Watsonx  Deployment Space and tested with real student queries
❖This AI -powered agent simplifies the admission process, reduces manual queries, and 
improves access to reliable, up -to-date information.

❖RAG Architecture:
▪Retrieval: Tavily /Wikipedia fetch real -time info
▪Augmentation: Retrieved content injected into the prompt

CONCLUSION
The College  Admission  Agent  developed  using  IBM  Watsonx .ai successfully  
demonstrates  the power  of Retrieval -Augmented  Generation  (RAG)  in simplifying  the 
student  admission  process . By combining  the Granite -13B foundation  model  with real-
time data retrieval  through  tools  like Tavily  and Wikipedia,  the agent  provides  accurate,  
conversational  answers  to common  admission  queries . This AI-driven  solution  enhances  
accessibility,  reduces  manual  effort,  and ensures  that students  receive  timely  and reliable  
guidance  on eligibility,  courses,  cutoffs,  and colleges  — all through  a simple,  user-
friendly  interface  hosted  entirely  on IBM  Cloud .
